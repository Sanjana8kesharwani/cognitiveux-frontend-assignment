# Task 1: Exclusive Privileges Section

I recreated the ICICI Bank Exclusive Privileges section using HTML, CSS, and Vanilla JavaScript.

### Features

* Responsive design
* Custom carousel implementation
* 3D coverflow effect
* Touch swipe support
* Mouse drag support
* Autoplay functionality
* Navigation controls
* Mobile-friendly layout

No external libraries or frameworks were used.


# Task 2: Video Chapters for YouTube Videos

Built an interactive YouTube video carousel with chapter navigation using HTML, CSS, and Vanilla JavaScript.

### Features

* YouTube video carousel
* Previous / Next navigation
* Video chapter timeline
* Chapter-based video seeking
* Active chapter highlighting
* Responsive design
* Dynamic chapter updates when switching videos
* Chapter timeline generator from YouTube URL
* Copyable JavaScript chapter configuration

No external UI frameworks were used.
